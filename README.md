### Overview
Japanese Quiz Master is a sleek, single-page web application designed for students and enthusiasts of the Japanese language. Whether you are preparing for the JLPT or simply brushing up on vocabulary and grammar, this tool provides an engaging, gamified environment to test your knowledge.

### Features
*   **Timed Challenges:** Put your speed to the test with a built-in countdown timer.
*   **Progress Tracking:** Visual progress bar to keep you motivated throughout the quiz.
*   **Score Summary:** Receive an instant breakdown of your performance upon completion.
*   **Instant Restart:** Jump back into the action immediately after finishing.
*   **Responsive Design:** Fully optimized for both desktop and mobile browsers.

### Localization Notes
*   **Language:** Content is localized for the Japanese market, utilizing native phrasing and cultural context.
*   **Layout:** Designed with LTR (Left-to-Right) text flow, while ensuring full compatibility for Japanese character rendering (Kanji/Kana).
*   **Formatting:** Date and numerical formats follow local Japanese standards.

### Tech Stack

*   **Styling:** Modern CSS (Flexbox & CSS Grid)
